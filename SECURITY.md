# Security

This alpha uses local Bluetooth and does not expose a network server, execute movement commands or write desk settings. It has not received a third-party security audit.

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/solarssk/ha-linak/security/advisories/new). Do not post credentials, device identifiers or unredacted Bluetooth logs in public issues.

The latest development branch is supported during the alpha. Dependency updates, secret scanning, tests and HA packaging validators run in CI. These checks do not certify hardware safety or occupancy detection.
